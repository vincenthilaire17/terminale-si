📖 DOCUMENT RESSOURCE : Fonctions & Syntaxe MicroPython Utiles

• from machine import Pin, ADC, PWM
• led = Pin(15, Pin.OUT) : sortie TOR
• led.value(1) / led.value(0) : 3.3V ou 0V
• bp = Pin(14, Pin.IN, Pin.PULL_DOWN) : 0V repos, 3.3V pressé
• bp = Pin(14, Pin.IN, Pin.PULL_UP) : 3.3V repos, 0V pressé
• etat = bp.value() : renvoie 0 ou 1
• pot = ADC(Pin(26)) ou ADC(26) : entrée CAN 12b (0 à 3.3V)
• N = pot.read_u16() : quantification 16 bits (0 à 65535)
• V_in = (N / 65535) * 3.3 : tension mesurée
• buz = PWM(Pin(16)) ; buz.freq(440) : fréquence en Hz
• buz.duty_u16(val) : génération PWM (0 = éteint, 32768 = actif à 50%)
• import time ; time.sleep(sec) : tempo

DOCUMENT PROFESSEUR — CORRIGÉ DÉTAILLÉ & BARÈME (/20)

Exercice 1 : Analyse Bouton & Clignotement (4 points)

1.1. Rôle de Pin.PULL_UP (1 pt) : Active la résistance de tirage interne reliant la broche au 3.3V. Cela évite l'état "flottant" (haute impédance sensible aux parasites électromagnétiques). Bouton relâché : potentiel = 3.3 V, valeur renvoyée = 1.
1.2. Condition if not etat_bouton: (1 pt) : Lorsque le bouton est pressé, la broche est reliée au 0V (masse GND), donc etat_bouton = 0 (False). L'opérateur not inverse l'état : not 0 donne True. La condition est donc validée quand le bouton est pressé.
1.3. Comportement de clignoter(3, 0.2) (1 pt) : La boucle range(3) exécute 3 cycles d'allumage (0.2s) et d'extinction (0.2s). Il y a donc 3 éclats lumineux. Durée totale : 3 × (0,2 s + 0,2 s) = 1,2 seconde.
1.4. Principe DRY (1 pt) : Évite la répétition de code (*Don't Repeat Yourself*), modularité, facilite la maintenance et permet de changer la cadence ou le nombre d'éclats par un simple appel de paramètre.

Exercice 2 : CAN & Asservissement PWM (4 points)

2.1. Calcul de tension (1 pt) : Vin = (43690 / 65535) × 3,3 V = 2,20 V.
2.2. Fréquence et Période (1 pt) : Fréquence du son = 500 Hz (hauteur de note). Période T = 1 / f = 1 / 500 = 0,002 s = 2 ms.
2.3. Modulation PWM & Dessin du signal (1 pt) :
• Signification de 32768 (0,5 pt) : 32768 correspond à la moitié de 65535 (50 % du temps au niveau haut 3,3 V, onde carrée symétrique à mi-puissance).
• Dessin du signal (0,5 pt) : Signal créneau de période T = 2 ms, avec 1 ms à l'état haut (3,3 V) et 1 ms à l'état bas (0 V).
2.4. Tableau de comportement (1 pt) :
• Vin < 1,1 V : valeur 0 → Buzzer silencieux / éteint.
• 1,1 V ≤ Vin < 2,2 V : valeur 16384 → Buzzer actif à volume modéré.
• Vin ≥ 2,2 V : valeur 32768 → Buzzer actif à volume maximal.
