Prérequis fondamental aux Trames de communication série et au Traitement de l'Information Numérique

🎯 Objectifs & Compétences du Programme de Terminale SI

  • Compétence B2 / CO2.1 : Caractériser les échanges d'information entre composants (structure d'une trame série, délimiteurs de début/fin, octet de commande, assemblage de données sur plusieurs octets MSB/LSB, contrôle d'erreur par Checksum).
  • Compétence B1 / CO1.2 : Traiter et coder l'information : convertir et manipuler les grandeurs numériques dans les bases 2, 10 et 16, maîtriser la règle des quartets et le découpage en octets.
  • Compétence C1 / CO3.1 : Manipuler les représentations de données dans un système numérique (binaire naturel, puissances de 2, octets, hexadécimal, masquage de bits, code ASCII, pilotage d'afficheurs 7 segments).

🧭 Pourquoi cette activité est-elle le socle de vos futurs TPs de Terminale SI ?

Dans un système mécatronique moderne (robotique, banc d'essai, drone, chaîne de tri automatisée) :

  • Côté Traitement des Données : Les processeurs et microcontrôleurs manipulent l'information sous forme de registres de 8, 10, 12 ou 16 bits. L'ingénieur doit savoir passer instantanément de la valeur binaire brute à son écriture hexadécimale compacte et à sa grandeur réelle décimale.
  • Côté Communication (Le transport des données dans une trame) : Pour envoyer des mesures à un microcontrôleur ou un afficheur (sur une liaison série UART, SPI ou I²C), les bits sont organisés en octets successifs formant une trame. Une mesure de 10 ou 16 bits ne tenant pas dans un seul octet, elle doit être découpée en un octet de poids fort (MSB) et un octet de poids faible (LSB), puis encadrée par des octets de synchronisation et de contrôle.

⚡ Défi 1 : Le Registre d'État des Capteurs Tout-Ou-Rien (TOR)
Niveau : Débutant • 4 pts

Le bus de diagnostic renvoie l'état binaire d'un registre 8 bits (1 octet) connecté aux capteurs Tout-Ou-Rien (fin de course, niveau de batterie, détection d'obstacle) :

REG_ETAT = 11010110₂

Rappel d'ingénierie : Dans un registre binaire de 8 bits numérotés de b7 (poids fort / MSB) à b0 (poids faible / LSB), la valeur décimale est donnée par le développement positionnel en base 2 :

N10 = ∑i = 07 (bi × 2i) = (b7 × 128) + (b6 × 64) + (b5 × 32) + (b4 × 16) + (b3 × 8) + (b2 × 4) + (b1 × 2) + (b0 × 1)

Questions Défi 1 :

  1. Q1.1 : Calculez la valeur décimale exacte du mot d'état 11010110₂ en détaillant la somme des puissances de 2 actives.
  2. Q1.2 : Convertissez ce mot d'état directement en Hexadécimal (base 16) en le découpant en deux quartets (groupes de 4 bits). Précisez la valeur de chaque quartet.
  3. Q1.3 (Code Secret n°1) : Si la valeur décimale est paire, le code de validation CLE_1 est le résultat décimal divisé par 2. Quelle est la valeur de CLE_1 ?
🎛️ Défi 2 : Le Capteur Numérique de Pression & Registre 10 bits
Niveau : Intermédiaire (Mot 10 bits) • 5 pts

Le rover surveille la pression dans son réservoir d'oxygène à l'aide d'un capteur numérique communicant (liaison I²C). Ce capteur transmet la valeur mesurée sous la forme d'un mot numérique sur 10 bits stocké dans un registre processeur embarqué.

📐 Rappels : Mots Numériques sur 10 bits et au-delà :

  • Nombre de combinaisons : Pour un mot de n bits, il y a 2n combinaisons binaires possibles (de 0 à 2n − 1). Sur 10 bits : 210 = 1024 valeurs (de 0 à 1023).
  • Poids des bits d'un mot 10 bits :
    b9: 512 • b8: 256 • b7: 128 • b6: 64 • b5: 32 • b4: 16 • b3: 8 • b2: 4 • b1: 2 • b0: 1
  • Conversion Hexadécimal → Binaire : Chaque symbole hexadécimal correspond à 4 bits (un quartet). Pour 0x0280 : 0x2 = 0010₂ et 0x8 = 1000₂ et 0x0 = 0000₂.

🛰️ Défi 4 : L'Interception & le Décodage de la Trame Série du Capteur
Niveau : Avancé (Pont Trames Série & Checksum) • 6 pts

Le bus de communication série du rover transmet un flux d'octets bruts issu de la centrale d'acquisition. Voici la trame de 12 octets exactement capturée dans le tampon mémoire (buffer série) :

55 AA 02 03 E8 2A 43 41 46 45 25 0D

📦 Rappels d'Ingénierie : Qu'est-ce qu'une Trame Série ?

Dans un système embarqué, une mesure brute ne peut pas voyager seule. Pour être reconnue et protégée contre les parasites, elle est encapsulée dans une trame composée de plusieurs champs normés :

Champ Octets Rôle technique dans le protocole
Préambule & Start 0x55 puis 0xAA Synchronisation d'horloge et délimiteur marquant le début certain de la trame.
Code Commande 0x02 Identifie la nature des données transmises (0x02 = Trame de télémesure capteur).
Mesure (MSB + LSB) 0x03 puis 0xE8 Une mesure codée sur 16 bits (2 octets). MSB = octet de poids fort, LSB = octet de poids faible.
État Actionneurs 0x2A Mot d'état binaire (masque logique des relais et électrovannes actifs).
Message ASCII 0x43 0x41 0x46 0x45 Texte de diagnostic où chaque octet représente une lettre selon la norme ASCII.
Checksum (Contrôle) 0x25 Somme de contrôle d'intégrité : Somme de tous les octets utiles modulo 256.
Stop 0x0D Délimiteur marquant la fin de la trame (caractère standard CR - Retour chariot).

Exercice 1 : Décodage et Contrôle d'Intégrité d'une Trame Capteur Ultrason
5 points

Un capteur de distance à ultrasons émet périodiquement sur sa sortie série une trame de 5 octets :

0xFF   0x01   0x02   0xD4   0xD7

Le constructeur spécifie le protocole suivant :

  • Octet 0 : En-tête obligatoire fixe (0xFF).
  • Octets 1 et 2 : Distance mesurée en millimètres, transmise en 2 octets : Distance_MSB puis Distance_LSB.
  • Octet 3 : Indicateur de qualité du signal (force de l'écho, de 0 à 255).
  • Octet 4 : Somme de contrôle (Checksum) définie par : Checksum = (Octet 0 + Octet 1 + Octet 2 + Octet 3) mod 256.
  1. Reconstituez le mot hexadécimal de 16 bits représentant la distance (en associant l'octet MSB 0x01 et LSB 0x02).
  2. Calculez la distance mesurée par le capteur en millimètres (d10), puis convertissez-la en mètres.
  3. Quelle est la valeur décimale de la force du signal (Octet 3 = 0xD4) ?
  4. Vérifiez par le calcul si la trame est valide en calculant la somme des 4 premiers octets modulo 256. La trame a-t-elle été corrompue ?
Exercice 2 : Décodage Binaire d'un Afficheur 7 Segments & Masquage Logique
5 points

Brochage standard (Cathode commune)

Un afficheur 7 segments à cathode commune est piloté par un port 8 bits d'un microcontrôleur. Chaque bit commande l'allumage d'une DEL selon l'organisation standard du mot d'octet ci-dessous :

[ b₇: DP | b₆: G | b₅: F | b₄: E | b₃: D | b₂: C | b₁: B | b₀: A ]

(Convention logique active : 1 = Segment allumé, 0 = Segment éteint. Broche 8 ou 3 reliée au GND).

  1. Pour afficher le chiffre '3' (segments allumés : a, b, c, d, g ; point décimal DP éteint), déterminez l'état de chacun des 8 bits. Donnez le mot binaire complet de commande, puis convertissez cet octet en hexadécimal (0x...).
  2. Pour afficher le chiffre '8' avec le point décimal DP allumé (tous les segments allumés), donnez l'octet binaire et sa valeur hexadécimale associée.
  3. Le microcontrôleur exécute l'instruction de masquage logique bit-à-bit : ETAT = 0x4F AND 0x0F. Écrivez les deux opérandes en binaire, effectuez l'opération logique ET et donnez la valeur binaire et hexadécimale du résultat. À quoi sert ce masquage en pratique ?
Exercice 3 : Chronogramme d'Émission Série Asynchrone (UART)
5 points

Une liaison série asynchrone (UART) configurée à la vitesse normalisée de 9600 bauds (9600 bits par seconde) transmet des caractères entre un capteur et un microcontrôleur. Le protocole utilise le format standard 8N1 :

  • Niveau de repos de la ligne : état logique '1' (3,3 V).
  • 1 bit de Start : toujours à '0' (front descendant pour réveiller le récepteur).
  • 8 bits de données : transmis en commençant par le bit de poids faible (LSB en premier).
  • 1 bit de Stop : toujours à '1' (retour à l'état de repos).
  1. Calculez la durée Tbit d'un seul bit en microsecondes (μs) à 9600 bauds (Tbit = 1 / 9600).
  2. Combien de bits au total (Start + Données + Stop) sont émis pour transmettre 1 seul octet ? En déduire le temps total d'émission d'un octet en millisecondes.
  3. On transmet l'octet hexadécimal 0x53 (qui correspond à la lettre 'S' en ASCII). Donnez son écriture binaire sur 8 bits, puis donnez la séquence exacte des 10 niveaux logiques transmis sur la ligne dans l'ordre chronologique.

🔌 Câblage Matériel : Matrice LED 8×8 Grove (I²C) ↔ Raspberry Pi Pico

  • Broche SCL (Horloge I2C) : Connectée sur GP9 (Broche physique 12 du Pico).
  • Broche SDA (Données I2C) : Connectée sur GP8 (Broche physique 11 du Pico).
  • Alimentation VCC : 3V3(OUT) (Broche 36) ou VBUS 5V (Broche 40).
  • Masse GND : Broche 38 ou 3.
  • Adresse I²C par défaut : 0x70 (ou 0x77 selon le composant Holtek HT16K33).
MicroPython — main_matrice_8x8_pico.py (Prêt à l'emploi) Pilote I2C HT16K33 + Émulateur Console 
# ==============================================================================
# TP TERMINALE SI - PILOTAGE DE MATRICE DEL 8x8 EN MICROPYTHON (PICO RP2040)
# Decodage des notations Binaire (0b), Hexadecimale (0x) et Decimale
# ==============================================================================
from machine import Pin, I2C
import time

class Matrice8x8_HT16K33:
    """Pilote I2C pour matrice de DEL 8x8 Grove (controleur HT16K33)"""
    def __init__(self, bus_i2c, address=0x70):
        self.i2c = bus_i2c
        self.address = address
        # Sequence d'initialisation du HT16K33
        self.i2c.writeto(self.address, bytes([0x21]))  # Allume oscillateur
        self.i2c.writeto(self.address, bytes([0x81]))  # Affichage ON
        self.set_brightness(7)                         # Luminosite moyenne (0-15)
        self.clear()

    def set_brightness(self, level):
        """Regle la luminosite de 0 a 15"""
        level = max(0, min(15, int(level)))
        self.i2c.writeto(self.address, bytes([0xE0 | level]))

    def clear(self):
        """Eteint toutes les DELs"""
        self.show([0] * 8)

    def show(self, motif_8_lignes):
        """Envoie 8 octets a la matrice via I2C (1 ligne = 1 octet)"""
        buffer = bytearray(17)
        buffer[0] = 0x00
        for i in range(8):
            buffer[1 + 2 * i] = motif_8_lignes[i]
            buffer[2 + 2 * i] = 0x00
        self.i2c.writeto(self.address, buffer)

def afficher_console(motif_8_lignes, titre="AFFICHAGE VIRTUEL"):
    """Simulateur de matrice dans la console Thonny (REPL)"""
    print(f"\n=== {titre} ===")
    for i, val in enumerate(motif_8_lignes):
        binaire = f"{val:08b}"
        pixels = "".join(["██" if b == '1' else "··" for b in binaire])
        print(f"L{i}: 0b{binaire} | 0x{val:02X} | {val:3d} | [{pixels}]")

# ------------------------------------------------------------------------------
# 1. INITIALISATION I2C
# ------------------------------------------------------------------------------
try:
    i2c = I2C(0, scl=Pin(9), sda=Pin(8), freq=100000)
    matrice = Matrice8x8_HT16K33(i2c, address=0x70)
    matrice_presente = True
    print("Matrice 8x8 physique connectee sur I2C0 (0x70) !")
except Exception:
    matrice_presente = False
    print("Matrice physique non detectee : Mode simulateur console Thonny actif.")

# ------------------------------------------------------------------------------
# 2. DEFINITION DES MOTIFS DANS LES 3 NOTATIONS (STRICTEMENT IDENTIQUES)
# ------------------------------------------------------------------------------

# Notation 1 : BINAIRE (0b...) - Dessin direct (1 = allume, 0 = eteint)
CADENAS_BINAIRE = [
    0b00111100,  # L0 : haut anse
    0b01000010,  # L1 : cotes anse
    0b01000010,  # L2 : anse fermee
    0b11111111,  # L3 : haut corps
    0b11100111,  # L4 : serrure
    0b11100111,  # L5 : serrure
    0b11111111,  # L6 : bas corps
    0b00000000   # L7 : eteint
]

# Notation 2 : HEXADECIMALE (0x...) - Format standard compact
CADENAS_HEXA = [
    0x3C, 0x42, 0x42, 0xFF, 0xE7, 0xE7, 0xFF, 0x00
]

# Notation 3 : DECIMALE - Poids bruts
CADENAS_DECIMAL = [
    60, 66, 66, 255, 231, 231, 255, 0
]

# Motif Deverrouille : Anse ouverte a gauche (L2 : 0b00000010 = 0x02 = 2)
CADENAS_OUVERT = [
    0x3C, 0x42, 0x02, 0xFF, 0xE7, 0xE7, 0xFF, 0x00
]

# ------------------------------------------------------------------------------
# 3. DEMONSTRATION D'EQUIVALENCE STRICTE
# ------------------------------------------------------------------------------
print("\n--- VERIFICATION EN MEMOIRE ---")
print("CADENAS_BIN == CADENAS_HEX == CADENAS_DEC ?", CADENAS_BINAIRE == CADENAS_HEXA == CADENAS_DECIMAL)

# ------------------------------------------------------------------------------
# 4. ANIMATION DEVERROUILLAGE (FERME -> OUVERT)
# ------------------------------------------------------------------------------
for tour in range(2):
    afficher_console(CADENAS_BINAIRE, "CADENAS FERME (VERROU)")
    if matrice_presente:
        matrice.show(CADENAS_BINAIRE)
    time.sleep(1.5)

    afficher_console(CADENAS_OUVERT, "CADENAS OUVERT (DEVERROUILLE)")
    if matrice_presente:
        matrice.show(CADENAS_OUVERT)
    time.sleep(1.5)

print("\nProgramme termine !")
